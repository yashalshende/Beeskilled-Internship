WEEK 2 DELIVERABLES & ARCHITECTURAL HIGHLIGHTS
--------------------------------------------------------------------------------
1. Foundation (Express.js & MongoDB):
   • Modular MVC architecture (src/{config, controllers, middleware, models, routes, tests, utils}).
   • Robust Mongoose database connection lifecycle management with reconnection handlers.
   • Helmet security headers, CORS origin management, and centralized error handling with custom API envelopes.
   • Public health telemetry endpoint at GET /api/health.

2. Assignment 1: To-Do List REST API:
   • Complete CRUD endpoints: POST, GET (all), GET (:id), PUT (:id), DELETE (:id).
   • Advanced query support: pagination (?page=&limit=), completion filter (?completed=), regex title search (?search=), and sorting (?sort=).
   • Hexadecimal 24-character ObjectId validation preventing runtime database casting exceptions.

3. Assignment 2: User Authentication API:
   • Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/auth/profile, GET /api/auth/me.
   • Cryptographic password hashing using bcryptjs (10 salt rounds) with max 72-byte limit to prevent CPU exhaustion DoS.
   • Constant-time comparison on unknown users to mitigate email enumeration and timing attacks.
   • Stateless RFC 7519 JSON Web Token (JWT) issuance and Bearer token verification middleware with 7-day expiration.

4. Mini Project: Notes App Backend:
   • User-scoped notes with schema-level User references (ref: 'User').
   • Compound indexing ({ user: 1, createdAt: -1 }) for optimal query performance.
   • Strict cross-user authorization barriers: unauthorized modification or deletion returns HTTP 403 Forbidden.
   • Full CRUD functionality strictly isolated per authenticated user session.
