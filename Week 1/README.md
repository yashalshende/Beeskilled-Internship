## 🚀 Quick Run Guide

### Assignment 1: Personal Portfolio
Open `Week 1/Assignment 1 - Personal Portfolio/index.html` directly in any web browser, or:
```bash
npx -y serve "Week 1/Assignment 1 - Personal Portfolio"
```

### Assignment 2: React Component Practice
```bash
cd "Week 1/Assignment 2 - React Component Practice"
npm install
npm run dev
# App runs at: http://localhost:5174
```

### Mini Project: React Blog UI
```bash
cd "Week 1/Mini Project - React Blog UI"
npm install
npm run dev
# App runs at: http://localhost:5175
```
